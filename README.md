Pacman Edge Detection 🎮

This is a simple Pacman project made using HTML, CSS, and JavaScript.

In this project, Pacman moves automatically across the screen. 
When Pacman reaches the edge of the screen, it changes direction and starts moving back. 
The Pacman images are also changed while moving to create a simple animation.

Features:
Pacman moves automatically.
Detects the left and right edges of the screen.
Changes direction when it reaches an edge.
Uses different Pacman images for animation.
Simple and beginner-friendly JavaScript project.

Technologies Used:
HTML
JavaScript
